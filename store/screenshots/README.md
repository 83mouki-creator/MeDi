# Captures d'écran pour la fiche Google Play

À produire une seule fois, en portrait **1080 × 2400** (JPEG ou PNG, sans
transparence). La marche à suivre détaillée est dans `docs/PLAY-STORE.md`,
section 3.

| Fichier | Écran à capturer |
| --- | --- |
| `01-accueil.png` | page d'accueil (recherche + rayons) |
| `02-catalogue.png` | liste de produits avec les prix en FCFA |
| `03-fiche-produit.png` | fiche produit (photo, prix, stock) |
| `04-panier.png` | panier / récapitulatif de commande |
| `05-suivi.png` | suivi de commande |

Ces images servent seulement au dépôt Play : elles ne sont pas utilisées par le
site et peuvent rester hors du dépôt Git.
